# [Scarlab Icons](http://scarlab-icons.la-moore.ru/)
Scarlab Icons is a collection of more than 1400 simple, beautiful and open source icons. Each icon is designed on a 24x24 grid with an emphasis on simplicity, consistency, and flexibility.

```shell
npm install @scarlab-icons/svelte
```

### Include
```svelte
<script>
  import SolidSquareIcon from '@scarlab-icons/svelte/solid/square.svelte'
  import SolidCircleIcon from '@scarlab-icons/svelte/solid/circle.svelte'
  import CircleIcon from '@scarlab-icons/svelte/outline/circle.svelte'
</script>
```

### Use

```svelte
<CircleIcon
    width="32"
    height="32"
    stroke-width="3"
    style="color: #ff6800;"
/>
```
