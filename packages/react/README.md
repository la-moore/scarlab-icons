# [Scarlab Icons](http://scarlab-icons.la-moore.ru/)
Scarlab Icons is a collection of more than 1400 simple, beautiful and open source icons. Each icon is designed on a 24x24 grid with an emphasis on simplicity, consistency, and flexibility.

[scarlab-icons](http://scarlab-icons.la-moore.ru/)

```shell
npm install @scarlab-icons/react
```

### Include
```jsx
import { SolidSquare, SolidCircle } from '@scarlab-icons/react/solid'
import CircleIcon from '@scarlab-icons/react/outline/circle'
```

### Use

```jsx
<CircleIcon
    width={32}
    height={32}
    strokeWidth={3}
    style={{ color: '#ff6800' }}
/>
```
